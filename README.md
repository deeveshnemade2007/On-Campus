# 🎓 On Campus

**On Campus** is a centralized college platform where students and teachers can view **department updates, events, functions, club activities, and announcements**. It also provides an online **event enrollment and slot booking system**.

## 🏫 Departments

The platform includes 8 department portals:

* Computer Engineering
* Computer Science & Engineering
* CSE (Artificial Intelligence)
* Artificial Intelligence & Data Science
* Mechanical Engineering
* Electronics & Telecommunication
* Information Technology
* Electronics & Computer Engineering

## 👥 User Portals

### 1. Director

* View overall department and club updates
* Monitor activities and progress

### 2. HOD

* Access only their own department portal
* Manage coordinators
* Verify and approve events
* Monitor department activities

### 3. Coordinator

* Create and update events
* Submit events for HOD verification
* Manage event slots and registrations

### 4. Student

* View events and updates
* Enroll in events
* Book available slots
* View booking status

## 🔄 Event Workflow

**Coordinator → HOD Verification → Event Published → Student Enrollment → Slot Booking**

## 🛠️ Technology

* **Frontend:** React.js
* **Backend:** Node.js / Express.js
* **Database:** PostgreSQL
* **Authentication:** Role-Based Access Control

## 🎯 Goal

To create a **single digital campus platform** that connects departments, management, coordinators, and students while simplifying **event management and slot booking**.
